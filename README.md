# Click

The browser extension for one-click wallet login

This extension allows you to connect your wallet to all websites you visit, your wallet connects via the WalletConnect protocol, so you can have your wallet on a separate device, like your phone, and still be able to login and sign transactions.

## Installation

### Chrome Web Store

[Download](https://chromewebstore.google.com/detail/brume-click/kjlnlaliaghojddgclpnjelooempnkfm)

### Self-install

Just [download the .zip](../../releases) and extract it, then go to Chrome "extensions" page, enable "Developer mode" and load the folder.
